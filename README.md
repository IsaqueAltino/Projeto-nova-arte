# Nova Arte — site do TCC

# Páginas
- `index.html`: apresentação do TCC, missão, valores, acessibilidade e equipe.
- `comunidade.html`: área social separada, inspirada em galerias visuais, com feed em mosaico, busca, categorias, perfis, favoritos e publicações.
- `style.css`: todo o visual responsivo.
- `script.js`: interações e armazenamento local.
- `assets/`: seis obras ilustrativas abstratas para demonstração.
